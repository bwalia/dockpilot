The gap

CLI is powerful. Context-switching is not.

Jumping between docker ps, logs, exec, and compose files slows incident response when you need a clear view of the host.

Without DockPilot

Scattered terminals, stale metrics, copy-paste commands, and no shared place to inspect stacks or turn AI findings into runnable steps.

With DockPilot

One warm dashboard for lifecycle actions, live logs, terminal, Compose, resources, and local Ollama analysis — self-hosted on your machine.

Capabilities

Everything you reach for during an incident

Built for operators who already know Docker — faster feedback, fewer tabs.

Instant live dashboard

Warm metrics cache serves KPIs in tens of milliseconds, then refreshes CPU, memory, and status in place.

In-browser terminal

Open a real shell into any running container over WebSocket — no SSH hop required.

Live log streaming

Follow logs over SSE with tail, filter, and download — not a one-shot dump.

Compose stack control

Group services by project and run up, pull, restart, stop, or down as one unit.

Local AI analysis

Ask Ollama to diagnose a container and turn findings into saved, runnable runbooks.

Hardened by default

Basic Auth, CSRF on mutations, and security headers so a cockpit on the LAN stays gated.

Workflow

Four steps from noise to action

A short loop you can run all day without leaving the browser.

Find

Filter the container table by name, image, state, or ports.

Act

Start, stop, restart, inspect, or open logs and terminal.

Ask

Run AI analysis when a container looks wrong or logs are noisy.

Apply

Execute suggested Docker commands or save them as a runbook.

Get started

Install and run in minutes

Source, binary, or Docker — pick the path that matches your host.

git clone https://github.com/bwalia/dockpilot.git
cd dockpilot
go build -o dockpilot .
./restart.sh
# open http://localhost:8090/
# from project root
chmod +x dockpilot
./restart.sh
./status.sh
docker build -t dockpilot:local .
docker run --rm -p 8090:8090 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  dockpilot:local

Take the helm on your Docker host.

Self-hosted, open source, and built for operators who want speed without giving up control.
